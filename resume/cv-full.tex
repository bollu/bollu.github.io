\section{Summary}
ML Performance Engineer at \textbf{XTX Markets}; PhD researcher (Cambridge) working on formally
verified decision procedures and mechanical theorem proving in Lean, with a focus on compiler
verification.
Co-developer of Lean's \bvdecide{} bitvector solver (\textbf{5th at SMT-COMP 2025}, \qfbv{}) and
author of sound-and-complete, machine-checked decision procedures for parametric bitvectors.
Also a decade of performance-critical \cpp{} inside production compilers and low-level runtimes:
\#3 contributor to \textbf{Polly} (LLVM's polyhedral loop optimizer) and primary author of
\textbf{Lean's LLVM backend}, lowering an IR through instruction selection and code generation
down to native machine code.
Comfortable reasoning about the machine underneath the language --- cache behaviour, memory
models, SIMD, assembly --- and optimizing hot code to that level.
\par\vspace{1pt}
